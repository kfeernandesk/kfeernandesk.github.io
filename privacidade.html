Política de Privacidade

Última atualização: 8 de novembro de 2026.

1. Sobre o projeto

O LoopingBR Publisher é um projeto de uso pessoal para preparar e executar publicações autorizadas de vídeos no YouTube. A operação utiliza Google Drive, YouTube Data API e GitHub Actions. O site público é uma página de apresentação e documentação; não é o local onde as contas Google são conectadas.

2. Dados e permissões acessados

Com a autorização da conta Google utilizada pelo responsável, o aplicativo pode:

  • Consultar informações necessárias para identificar o canal YouTube autorizado e validar que a publicação será enviada ao canal configurado.
  • Ler e baixar arquivos específicos do Google Drive informados para publicação, incluindo vídeos e miniaturas.
  • Enviar vídeos ao YouTube e, quando solicitado, definir título, descrição, público infantil, visibilidade, miniatura e horário de publicação.

As permissões OAuth configuradas para esse fluxo incluem youtube.upload, youtube.readonly e drive.readonly. A permissão de leitura do Drive é ampla em nível técnico, mas o fluxo do Publisher é destinado a processar os IDs de arquivos escolhidos para a publicação, não a analisar toda a conta.

3. Finalidade do tratamento

Os dados são usados para preparar, validar e executar publicações solicitadas pelo responsável, evitar envios repetidos e permitir a conferência do resultado. Eles não são utilizados para vender perfis, direcionar anúncios ou realizar publicações sem aprovação explícita.

4. Armazenamento e retenção

As credenciais e autorizações usadas pela automação são configuradas como segredos do GitHub Actions no repositório privado de operação. Os pedidos de publicação, identificadores de arquivos e resultados podem ficar registrados nesse repositório privado. Registros de execução podem ser mantidos pelo GitHub de acordo com suas configurações e políticas de retenção.

Os arquivos de mídia são baixados temporariamente durante a execução e não são destinados a armazenamento permanente pelo publicador. Ao concluir a tarefa, o ambiente temporário da execução é descartado segundo o funcionamento do GitHub Actions. Os vídeos enviados passam a ser armazenados no YouTube, sujeito às políticas e configurações do serviço. Os arquivos originais continuam no Google Drive até que o titular os modifique ou exclua.

5. Serviços externos e compartilhamento

O funcionamento depende dos serviços do Google (Drive e YouTube) e do GitHub (repositórios privados e GitHub Actions). O tratamento técnico de dados por esses provedores segue seus próprios termos e políticas. Não há venda de dados a anunciantes pelo LoopingBR Publisher.

Consulte a Política de Privacidade do Google e a declaração de privacidade do GitHub.

6. Revogação de acesso e exclusão

O titular pode revogar o acesso concedido ao aplicativo na página de conexões da Conta Google. Também pode excluir vídeos pelo YouTube Studio e arquivos originais pelo Google Drive. Registros internos de pedidos e resultados devem ser gerenciados separadamente no repositório privado pelo responsável. A revogação interrompe novas operações autorizadas, mas não remove automaticamente vídeos já publicados.

7. Sobre este site

Este site estático não possui formulários de cadastro, autenticação ou coleta intencional de dados pessoais, nem inclui scripts próprios de análise de audiência. O serviço de hospedagem GitHub Pages pode processar informações técnicas de acesso, conforme a política do GitHub.

8. Contato e atualizações

Para questões gerais sobre a documentação, utilize a área pública de questões do repositório, quando disponível. Não publique tokens, senhas ou informações pessoais sensíveis em comentários públicos. Questões que exijam compartilhamento de dados pessoais devem ser tratadas por um canal privado acordado com o responsável pelo projeto.

Esta política será atualizada caso as funcionalidades ou as práticas efetivas de tratamento de dados sejam modificadas.
